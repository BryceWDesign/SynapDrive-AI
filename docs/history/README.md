# Historical design records

These records document the source audit and proposed design that preceded the
executable 2.0.0 implementation. They are retained for provenance and research
traceability. Original source names, checksums and design-stage statuses refer
to those earlier artifacts.

For current behavior and results, see [implemented scope](../V2_IMPLEMENTED.md),
[requirement status](../REQUIREMENT_STATUS.json), and [measured results](../../RESULTS.md).
The archived design-check source is stored as text rather than active release commands.
