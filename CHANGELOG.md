# Changelog

## 2.0.0

Implemented strict canonical admission, exact commands/capabilities, durable dispatch
permits and recovery, real recorded-EEG train/calibrate/evaluate/infer, acquisition identity
and freshness, local access/privacy tasks, evaluator-owned decoder updates, delayed
feedback retraction, contextual replay, signed completeness checkpoints, and independent
fault/plant validation. Repaired the reproduced baseline defects within the documented
trusted simulation scope and added behavioral regressions.

Added an attributed processed PhysioNet subset, exact source hashes, fitted numeric-only
models, predictions, failure counts and a reproducible fixed split. Retained the original
design/audit as historical records and mapped incomplete requirements explicitly.

This is a software research release. Reliable neural access, human benefit and physical
safety are unestablished; the recorded-data failures are disclosed in `RESULTS.md`.
